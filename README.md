# Vishal Ellure | Interactive 3D Portfolio

A high-performance, futuristic 3D developer portfolio showcasing the work of **Vishal Ellure**, Computer Science & Engineering undergraduate at **RV College of Engineering (RVCE), Bengaluru** (CGPA: 9.28).

Built using **React 18**, **Three.js**, **@react-three/fiber**, **@react-three/drei**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ or v20+)
- npm

### Installation
```bash
npm install --legacy-peer-deps
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
